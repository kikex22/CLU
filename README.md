# CLU
Central Learning Unit (Machine Learning) 

CLU is a modular system focused on Machine Learning, designed to learn and adapt within virtual or physical environments. It uses Deep Q-Learning (DQN) to make decisions and improve performance over time through interaction and experience. CLU can be trained in simulation and then deployed in real-world systems, enabling intelligent navigation, obstacle avoidance, and goal-oriented behavior.

In a future version, CLU will be integrated into EMMA-mk1 to transform it into an autonomous vehicle, combining real-time sensor monitoring with adaptive decision-making for full autonomy.
